```
┌─────────────────────────────────────────────────────────────────┐
│  🔐 Google OAuth2    →   Spring Security session management     │
│  🤖 Spring AI 1.1.2  →   Gemini · Groq LLaMA 3.1 · Ollama      │
│  🗄️  MongoDB Atlas   →   Auto-registers users on first login    │
│  🎨 React + Vite     →   Aged paper UI · Stamps · Typewriter    │
│  ⚡ Parallel fetch   →   All 3 models fire simultaneously       │
```
